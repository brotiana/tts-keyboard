Dictée clavier : préparer vos modèles

Ces modèles comprennent le français. Ils fonctionnent avec cette application au format faster-whisper / CTranslate2. Commencez par base et gardez tiny en secours.

À télécharger au cybercafé, pas maintenant si votre connexion est limitée.

Cette page peut être consultée hors ligne et ne charge aucune ressource distante. Seul un clic sur un lien de téléchargement ouvre Internet. Téléchargez les quatre fichiers de chaque modèle choisi.

Il faut aussi les bibliothèques Python : avec Python et pip disponibles au cybercafé, lancez python3 preparer_hors_ligne.py (Windows : py preparer_hors_ligne.py). Rapportez tout le dossier wheelhouse/ avec le code et les modèles.

tiny ≈ 78,2 Mo

Le plus léger, à garder comme secours. Enregistrez les quatre fichiers dans models/tiny/.

  • config.json
  • model.bin
  • tokenizer.json
  • vocabulary.txt

Voir les fichiers sur le dépôt officiel Systran

Où placer les fichiers ?

tts keyboard/
├── app.py
├── models/
│   ├── tiny/
│   │   ├── config.json
│   │   ├── model.bin
│   │   ├── tokenizer.json
│   │   └── vocabulary.txt
│   └── base/
│       ├── config.json
│       ├── model.bin
│       ├── tokenizer.json
│       └── vocabulary.txt
└── wheelhouse/
    └── les paquets .whl téléchargés

Conservez les noms exacts : pas de model (1).bin, ni de config.json.txt. Les variantes .en et les modèles .pt ne conviennent pas.

Si Python est disponible au cybercafé, le téléchargement automatique avec reprise et vérification SHA256 est plus simple :

python3 telecharger_modeles.py tiny base
python3 preparer_hors_ligne.py

Sous Windows, remplacez python3 par py. Pour plus de modèles : ajoutez small medium à la première commande.

Chez vous, ouvrez un terminal dans le dossier du code :

bash installer.sh
bash lancer.sh

L'installation est hors ligne par défaut. Les composants système python3-venv, python3-tk et libportaudio2 doivent être disponibles sur Linux Mint. Consultez README.md pour les prérequis et le dépannage.
